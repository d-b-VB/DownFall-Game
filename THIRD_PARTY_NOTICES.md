# Third-party notices

## Noto Emoji

DownFall renders Unicode emoji using the Noto Emoji artwork from the
[googlefonts/noto-emoji](https://github.com/googlefonts/noto-emoji) project.
The browser requests the SVG artwork from the pinned Noto Emoji `v2.051`
release through jsDelivr.

Noto Emoji's README states that most image resources are licensed under the
Apache License 2.0. The fonts are licensed under the SIL Open Font License 1.1.
The game uses the SVG image resources rather than the color font.
